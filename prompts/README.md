# Prompts

Mỗi prompt trong tutorial phải yêu cầu AI Agent:

1. Đọc source trong phạm vi được chỉ định.
2. Liệt kê evidence và uncertainty trước khi vẽ.
3. Không suy diễn component, edge, state hoặc failure path.
4. Gắn nhãn `CURRENT` cho hành vi đã được chứng minh.
5. Validate, render và báo receipt của Archify.
